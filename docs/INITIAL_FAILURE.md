# Демонстрація першого невдалого запуску Pint

За умовою лабораторної перша версія методу `add` повинна містити порушення форматування:

```php
public function add($x, $y)
{
return $x+$y;
}
```

Після відправлення такої версії у гілку `feature-cicd-pipeline` крок `Lint code with Pint` має завершитися помилкою. Цей запуск потрібно зафіксувати скріншотом для звіту.

Фінальна версія `app/Services/Calculator.php` уже виправлена: має стандартні відступи, пробіли навколо оператора `+`, строгі типи параметрів і тип результату. Вона повинна успішно пройти Pint і PHPUnit.

Не слід підміняти реальний лог GitHub Actions вигаданим скріншотом: доказом виконання етапу є фактичний невдалий запуск workflow, за яким іде успішний запуск після виправлення.

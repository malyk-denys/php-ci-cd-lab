# Лабораторна робота №3. Варіант 3

Тема: основи PHP, структури даних, функції, замикання, винятки та Composer.

## Відповідність методичці

За таблицею 3.1 варіант 3 відповідає задачам **2 / 3 / 7** з таблиць 3.2 / 3.3 / 3.4.
Предметна галузь успадкована з наявної лабораторної №2: продаж квитків до кінотеатру.
Номер варіанта алгоритмів цієї роботи не змінює вже створену UML-модель.

| Вимога | Реалізація |
|---|---|
| П'ять назв, `sort()`, HTML-списки | `app/Models/EntityArray.php` |
| Асоціативний масив з атрибутами UML | Order: id, customerId, screeningId, status, totalAmount, expiresAt |
| Типізована функція з двома аргументами | `calculateTotal(float $price, int $quantity): float` |
| Faker, 10 чисел, array_filter, closure з use | `index.php`: ціни 100–500 грн, критерій >250 грн |
| applyDiscount, виняток, try/catch/finally | `EntityService.php` та `index.php`, помилкова знижка 150% |
| Три функції варіанта 3 | `app/Services/DataProcessor.php` |
| Перевірки | `tests/Unit/*Test.php`, `scripts/verify-lab3.ps1` |

`calculateTotal()` реалізує операцію Order::calculateTotal() з UML у процедурному стилі.
На діаграмі операція бере стан об'єкта; тут ціна і кількість передані явно як два типізовані аргументи за вимогою лабораторної.
Для навчальних розрахунків використано float і округлення до двох знаків.

## Алгоритми та результати

1. `insertZerosAfterPositive([4, -2, 0, 7, -5, 1])` → `[4, 0, -2, 0, 7, 0, -5, 1, 0]`.
   Нуль не є додатним. Вхідний масив не змінюється, ключі результату послідовні.
   Елементи мають бути цілими числами; порожній масив повертає `[]`. Складність O(n).
2. `lastThreeWords('Сьогодні ми бронюємо квитки до кінотеатру')` → `квитки до кінотеатру`.
   Слова визначено як непорожні фрагменти між пробільними символами Unicode.
   Якщо слів менше трьох, повертаються всі; пунктуація зберігається, пробіли нормалізуються.
3. `digitsBeforeLetters('a3Б1c9Я2')` → `3192aБcЯ`.
   Групування стабільне: цифри й букви зберігають взаємний порядок у своїх групах.
   Підтримано Unicode, зокрема українські букви. Інші символи відхиляються винятком,
   оскільки за умовою вхід складається з цифр і букв. Порожній рядок дозволений. Складність O(n).

## Пояснення для захисту

- Composer встановлює залежності в `vendor/`; точні версії зберігає `composer.lock`.
- `use ($minThreshold)` захоплює значення зовнішньої змінної в замикання.
- `strict_types=1` у файлі виклику забороняє неявне перетворення рядка `'150'` на число;
  перевірка цього випадку очікує TypeError. Передача int у float дозволена PHP.
- Виконується `try`; за винятку — відповідний `catch`; потім `finally` незалежно від помилки.
- Помилка синтаксису призводить до невдалого CI; обов'язкові status checks блокують злиття PR.
- Атрибути UML задають ключі масиву Order, а операції класу — призначення функцій сервісу.
